## 다음 단계 (우선순위순)

### TASK 1: 경복궁 34개 지점 콘텐츠 리라이트 (최우선)

**목표**: palace_data.json의 34개 지점 설명을 v2 서사 공식으로 재작성.
**근거**: AGENTS.md의 핵심 지표 10개 지점이 모두 경복궁. 경복궁이 완성되어야 확장 기준 확보.

**적용 방식**:
- 34개 전부를 서사형(타입 B)으로 쓰지 않는다.
- **핵심 10개**: 서사 5단 구조 (훅→인간→사실→현재→초대), 400~700단어
  - 광화문, 흥례문, 근정전, 경회루, 향원정, 자경전, 건청궁, 신무문, 국립고궁박물관, 수정전
- **일반 24개**: 타입 A 즉답형 + 훅 1문장. 주소·가는 법·운영시간·소요시간 + 훅으로 시작.
  - 게이트류 (건춘문, 영추문, 융문당 등): "이 문은 ○○이 드나들던 문이다" + 간략 정보
  - 석수/장식류 (해치, 잡상, 석수 등): "이 조각은 ○○을 막기 위해 두었다" + 훅 + 즉답 정보

**데이터 소스**: `src/lib/palace_data.json` (khs.go.kr API 기반, 4개 국어 설명 포함)

**산출물**:
- `src/pages/palace/[id]/[code].astro` — 개별 지점 페이지 (또는 기존 페이지 리라이트)
- 콘텐츠 품질 기준: 무작위 10개 추출 시 모두 5단 구조 확인 가능해야 함

**주제 예**:
1. 청(靑) — 동쪽, 봄, 목. 단청에서 푸른색이 사용된 대표적 장소와 맥락.
2. 적(赤) — 남쪽, 여름, 화. 주홍색의 상징성과 실제 적용 사례.
3. 황(黃) — 중앙, 땅, 토. 황금색이 궁궐에서 갖는 위상.
4. 백(白) — 서쪽, 가을, 금. 석판치색과 단청 마감의 관계.
